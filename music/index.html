DATA NOTES

How to read this dashboard

Song identity is canonicalized.

Case, whitespace and straight/curly apostrophe differences are merged so “We’re All We Need” and “We're All We Need” count as the same song.

One chart = one song signal.

If the same song appears twice inside the same year/platform list, the Love Index keeps its best rank for that chart. The raw rows remain untouched.

No recency weighting.

A 2017 appearance is not discounted against a 2025 appearance. This is an all-time attachment score, not a “current favourites” score.

Rank matters.

Each valid chart appearance earns 101 − rank points before normalization, so #1 contributes 100 and #100 contributes 1.
