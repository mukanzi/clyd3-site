Data notes

How to read this system

Song identity is canonicalized.

Case, whitespace and straight/curly apostrophe differences are merged.

One chart = one song signal.

If the same song appears twice inside the same year/platform list, the Love Index keeps its best rank for that chart.

No recency weighting.

A 2017 appearance is not discounted against a 2025 appearance. This is an all-time attachment score.

Rank matters.

Each valid chart appearance earns 101 − rank points before normalization.
